# Describe для PF2e

Русская библиотека атмосферных описаний для игр Pathfinder Second Edition в Foundry VTT.

## Возможности

- 14 258 карточек с описаниями;
- поиск по названию, тексту и меткам;
- категории, папки и избранное;
- создание и редактирование собственных карточек;
- показ выбранной карточки игрокам;
- настройка прав доступа по ролям.

## Совместимость

- Foundry VTT 14.361–14.369;
- Pathfinder Second Edition 8.6.1.

## Установка

В Foundry VTT откройте «Дополнения» → «Установить модуль», вставьте адрес манифеста и нажмите «Установить»:

```text
https://github.com/yefim-lopatin/foundryvtt-describe/releases/latest/download/module.json
```

После установки включите модуль `Describe для PF2e` в настройках мира PF2e. Кнопка библиотеки появится среди инструментов заметок сцены.

## Использование

Ведущий может создавать и редактировать карточки, загружать собственные фоны и выбирать игроков, которым показывается описание. Права игроков на открытие библиотеки и показ карточек задаются в настройках модуля.

Изменения карточек сохраняются в данных конкретного мира Foundry VTT. Обновление модуля не переносит пользовательские изменения между разными мирами.
